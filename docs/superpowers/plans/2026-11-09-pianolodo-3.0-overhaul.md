# Pianolodo 3.0 Full-Stack Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Pianolodo into a professional-grade Piano Harmony Studio Cockpit 3.0 with dual-theme aesthetics, Circle of Fifths, tactile 3D keys, QWERTY live play, reverse chord detection, advanced voicing topologies, binary MIDI export, shareable URLs, and interactive practice gym.

**Architecture:** 
- Engine layer: Pure, deterministic TypeScript modules (`src/engine/`) for voice-leading, chord parsing, reverse chord detection, MIDI binary export, and URL serialization.
- Audio layer: `Tone.js` v15 Web Audio engines with robust timer cleanup, real-time `Tone.Analyser` spectrum data, and binaural stereo panning.
- UI layer: React 19 components with Tailwind v4, dual-theme (`theme-ivory` / `theme-dark`), VexFlow v5 dual-clef sheet notation with proper `Accidental` modifiers, and code-split chunks via Vite.

**Tech Stack:** React 19, TypeScript 5.7, Vite 7, Tailwind CSS v4, `@tonaljs/tonal`, `Tone.js`, `VexFlow` v5, Vitest, Lucide React.

---

## Global Constraints
- All new modules must have 100% unit test coverage in `src/__tests__/`.
- Every user-facing string must be translated in both `vi` and `en` in `src/i18n/translations.ts`.
- Zero Vite chunk warnings: `dist/` bundle chunks must be under 500kB with `manualChunks`.
- `npx tsc --noEmit` and `npm test` must pass with zero errors.

## Review Focus
1. **Low-Interval Limit on Diminished 5ths**: Left-hand bass on `Bm7b5` or `dim7` chords must never play a clash-inducing Perfect 5th.
2. **VexFlow Accidentals**: Notes with `#` or `b` must render with explicit `Accidental` modifiers on the stave.
3. **Web Audio Memory Safety**: Rapid chord scrubbing or stopping playback must cancel all active timeouts and pending audio events.
4. **QWERTY Key Mapping & Octave Shifts**: Keydown events must map cleanly without repeating or stuck notes when typing in text fields.
5. **Binary MIDI File Integrity**: The exported `.mid` file must be a byte-valid Standard MIDI File with `MThd` and `MTrk` headers.
